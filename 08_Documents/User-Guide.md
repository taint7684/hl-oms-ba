# Hướng dẫn nhanh — HL-OMS

Mỗi vai trò một mục, in một trang dán tại nơi làm việc (NFR-18). Đăng nhập: chọn tên → nhập PIN. Máy tự khóa sau 2 phút không dùng.

## Phục vụ

| Việc | Cách làm |
|---|---|
| Mở bàn | Sơ đồ bàn → chạm bàn xám (Trống) → số khách → **Mở bàn** |
| Gọi món | **+ Gọi món** → chọn danh mục hoặc gõ tên (không cần dấu) → món có tùy chọn: chạm **Chọn**; món thường: chạm **+** |
| Dị ứng | Trong bảng chi tiết món, chọn chất khách dị ứng. Thấy khung vàng "Món có chứa…" → báo khách đổi món |
| Gửi bếp | Đơn của bàn → kiểm tra với khách → **Gửi bếp** |
| Món xong | Điện thoại rung → mang món → **Đã mang ra** |
| Hủy món | Món Chờ nấu: **Hủy** + lý do. Món đã nấu: **Yêu cầu hủy** → chờ Quản lý duyệt |
| Chuyển / ghép bàn | Đơn của bàn → **⋯** → chọn bàn |
| Dọn bàn | Bàn tím (Cần dọn) → **Đã dọn** |

## Bếp

| Việc | Cách làm |
|---|---|
| Chọn trạm | Chạm tab Bếp nóng / Bếp lạnh / Quầy nước |
| Nấu món | Chạm món: Chờ nấu → **Đang nấu** → **Sẵn sàng** |
| Dải đỏ DỊ ỨNG | Đọc kỹ → **ĐÃ ĐỌC DỊ ỨNG** → mới nấu được |
| Phiếu cam / đỏ | Món đang trễ — làm trước |
| Cả phiếu xong | **Xong cả phiếu** |
| Màn hình lỗi | Chạm 🖨 để in phiếu, báo Bếp trưởng |

## Bếp trưởng

| Việc | Cách làm |
|---|---|
| Xem món đang chờ | Tab **Tổng hợp & tình trạng món** |
| Hết món | **Hết** — mọi điện thoại chặn món ngay |
| Còn ít phần | **Số phần** → nhập số; về 0 tự chuyển Hết |
| Bán lại | **Mở bán** |
| Bấm nhầm | Chạm **↶ Hoàn tác** dưới món |

## Thu ngân

| Việc | Cách làm |
|---|---|
| Tính tiền | Bàn và bill → chọn bàn. Nếu có khung đỏ: còn món chưa phục vụ, báo phục vụ |
| Giảm giá | **Giảm giá** → % hoặc số tiền + lý do. Trên 10%: chờ Quản lý duyệt |
| In bill tạm | **In bill tạm** cho khách kiểm tra |
| Tách bill | **Tách bill** → Theo món (chọn phần, chạm món) hoặc Chia đều (số phần) |
| Thu tiền | **Thanh toán** → EFTPOS (quẹt máy rồi xác nhận) hoặc Tiền mặt (nhập tiền khách đưa) → tick tax invoice nếu khách cần |
| Mang về | Tab Mang về → **+ Đơn mang về mới** → chọn món → **Thu tiền và gửi bếp** |
| Chốt ca | Tab Chốt ca → nhập tiền mặt đếm được → lệch trên $5 ghi lý do → **Chốt ca** |

## Quản lý

| Việc | Cách làm |
|---|---|
| Duyệt | Duyệt yêu cầu → **Duyệt** / **Từ chối** |
| Sửa menu | Quản lý menu → **Sửa** → lưu (giá mới chỉ áp cho món gọi sau đó) |
| Ngày lễ | Cấu hình → kiểm tra lịch ngày lễ, mức phụ thu |
| Báo cáo | Báo cáo → xem → **Xuất CSV** gửi kế toán |

## Admin

| Việc | Cách làm |
|---|---|
| Thêm nhân viên | Người dùng → **+ Thêm người dùng** → vai trò, PIN 4–6 số |
| Nhân viên nghỉ | **Khóa** tài khoản ngay ngày nghỉ |
| Quên PIN / bị khóa | **Đặt lại PIN** |
| Tra cứu | Nhật ký thao tác → lọc theo thao tác |
